# Проект: Влияние приложения для медитации на сон

## Цель проекта
Проверить с помощью статистических тестов, сокращает ли использование приложения для медитаций время засыпания.

## Данные
Данные содержат результаты 50 участников (возраст, время засыпания до и после). В данных присутствуют пропуски, дубликаты и аномалии, которые были очищены в ходе работы.

## Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. Откройте файл `project_sleep.ipynb` в Jupyter Notebook или PyCharm.
3. Выполните все ячейки (Kernel -> Restart & Run All).

## Главный вывод
Приложение статистически значимо сокращает время засыпания в среднем на 3.1 минуты (p-value < 0.001). Эффект сильнее выражен у участников младше 35 лет.
